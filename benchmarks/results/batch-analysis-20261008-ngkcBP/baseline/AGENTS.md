# Guidelines for working in this repository

## What is it

This is a WIP implementation of LMAX disruptor in zig

## Guidelines when interacting with the user

- Treat code as work in progress; do not point out unrelated bugs, incomplete code, or compilation errors unless the user explicitly asks you to review or diagnose them.
- Real disruptor code lives in ~/src/disruptor, you can reference the original implementation for comparison when needed to answer user query.
- When answering users question, try to give a complete answer for the question, but do not diverge onto the things that are not the subject of the question.
